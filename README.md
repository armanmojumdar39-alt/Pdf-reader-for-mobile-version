# PDF মার্কার — মোবাইল অ্যাপ (Android APK)

আপনার `pdf-marker-v2.html` প্রোগ্রামটিকে Capacitor দিয়ে অ্যান্ড্রয়েড অ্যাপে রূপান্তর করা হয়েছে।
APK বানাতে আপনার কম্পিউটারে কিছু ইনস্টল করা লাগবে না — GitHub নিজেই বিল্ড করে দেবে।

## APK বানানোর ধাপ

1. GitHub-এ নতুন একটি repository খুলুন (যেমন `pdf-marker`)।
2. এই ফোল্ডারের **সব ফাইল** (`.github` ফোল্ডারসহ) repository-তে আপলোড করুন।
   - ওয়েবে আপলোড করলে লুকানো `.github` ফোল্ডার বাদ পড়তে পারে। তাই ZIP খুলে ফোল্ডারটি সরাসরি টেনে আনুন, অথবা `git push` ব্যবহার করুন।
3. `main` ব্রাঞ্চে push হলেই বিল্ড নিজে শুরু হবে। হাতে চালাতে: **Actions → Build Android APK → Run workflow**।
4. ৫–১০ মিনিট পর বিল্ড শেষ হলে সেই run-এর নিচে **Artifacts → pdf-marker-apk** ডাউনলোড করুন।
5. ZIP খুলে `app-debug.apk` ফোনে নিয়ে ইনস্টল করুন (ফোনে “অজানা উৎস থেকে ইনস্টল” অনুমতি দিতে হবে)।

## মোবাইল ডিজাইন (নতুন)

- **নিচে টুল ডক:** ✋ পড়া, 🖍, U, S, ✏️, ▭, 📝, T, 🧽, ✂️ — আঙুলে সাইড-স্ক্রল করা যায়। রং ও কলমের মোটা ভাসমান প্যানেলে আসে।
- **ওপরে ছোট বার:** ☰ সাইডবার, ‹ পৃষ্ঠা › নেভিগেশন, ↶ ↷, আর ⋮ মেনু (জুম, বুকমার্ক, ডার্ক মোড, এক্সপোর্ট, Gemini সেটিংস, লাইব্রেরি)।
- **লেখা চেপে ধরে সিলেক্ট করলে** ভাসমান মেনু আসে: হাইলাইট/আন্ডারলাইন/কাটা, 🤖 ব্যাখ্যা, 🌐 অনুবাদ, কপি, Google সার্চ।
- **Gemini** এখন নিচ থেকে ওঠা শিট: উত্তর ওপরে, প্রশ্নের ঘর নিচে, বাকি অপশন “⋯ আরও অপশন”-এ।
- **দুই আঙুলে** জুম ও স্ক্রল — কলম/বক্স মোডেও কাজ করে।
- সাইডবার এখন ড্রয়ার, ব্যাক বাটন ধাপে ধাপে শিট/ড্রয়ার/টুল বন্ধ করে।
- বড় PDF-এ মেমোরি বাঁচাতে দূরের পৃষ্ঠার ছবি নিজে সরিয়ে ফেলা হয়।

## কী কী পরিবর্তন করা হয়েছে

| বিষয় | আগে | এখন |
|---|---|---|
| pdf.js / pdf-lib | ইন্টারনেট (CDN) থেকে | অ্যাপের ভেতরেই, অফলাইনে চলে |
| এক্সপোর্ট / ছবি / চ্যাট সেভ | ব্রাউজার ডাউনলোড (ফোনে কাজ করে না) | `Documents/PDF-Marker/` ফোল্ডারে সেভ + শেয়ার অপশন |
| কপি | ব্রাউজারের clipboard | Capacitor Clipboard |
| Google সার্চ | নতুন ট্যাব | অ্যাপের ভেতরের ব্রাউজার |
| টুলবার | একাধিক লাইনে ভাঙত | মোবাইলে সাইড-স্ক্রল করা যায় |
| ব্যাক বাটন | — | ডায়ালগ/সাইডবার বন্ধ করে, নাহলে অ্যাপ মিনিমাইজ |

PDF-এর মার্ক ও বুকমার্ক আগের মতোই ফোনের ভেতরে (IndexedDB) সেভ থাকে।
Gemini API Key অ্যাপের ⚙ সেটিংস থেকে দিতে হবে।

## ফাইল কাঠামো

```
www/index.html        আপনার মূল প্রোগ্রাম (মোবাইলের জন্য সামান্য সংশোধিত)
www/mobile.css / mobile.js  মোবাইল লেআউট ও টাচ ইন্টারঅ্যাকশন
www/native.js         ফাইল সেভ, কপি, ব্যাক বাটনের কোড
scripts/prepare-web.js  বিল্ডের সময় pdf.js ও pdf-lib কপি করে
capacitor.config.json   অ্যাপের নাম ও আইডি
.github/workflows/      APK বিল্ডের GitHub Actions
assets/                 অ্যাপ আইকন ও স্প্ল্যাশ
```

## নিজের মতো বদলাতে চাইলে

- **অ্যাপের নাম:** `capacitor.config.json`-এ `appName`
- **প্যাকেজ আইডি:** `appId` (যেমন `com.yourname.pdfmarker`)
- **আইকন:** `assets/icon-only.png` (1024×1024) বদলে দিন
- **HTML বদলালে:** শুধু `www/index.html` এডিট করে push করুন, নতুন APK তৈরি হবে

## জানা থাকা ভালো

- এটি **debug APK** — নিজে ব্যবহার ও বন্ধুদের দেওয়ার জন্য ঠিক আছে। Play Store-এ দিতে হলে signed release বিল্ড লাগবে (চাইলে বলবেন, workflow বানিয়ে দেব)।
- Android 9 বা তার আগের ফোনে `Documents`-এ সরাসরি সেভ না হলে অ্যাপ নিজে শেয়ার শিট খুলে দেবে।
- অ্যান্ড্রয়েডে ছবি সরাসরি ক্লিপবোর্ডে কপি হয় না, তাই “ছবি কপি” চাপলে ছবিটি ফাইল হিসেবে সেভ হবে।
